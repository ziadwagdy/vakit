# Security policy

Vakit is a community preview. Security fixes target the current `main` branch; no older release is separately maintained. It has not received an independent security audit.

Report exploitable vulnerabilities using [GitHub private vulnerability reporting](https://github.com/ziadwagdy/vakit/security/advisories/new). Include the affected commit, Ubuntu/Python versions, a minimal reproduction and impact. Do not publish working exploit details in a public issue before coordination. Never include credentials, private settings, or personal location/history files in an issue.

See the [security review](docs/SECURITY_REVIEW.md) for the threat model, completed checks, dependencies and distribution limitations. Re-run checks after changes to network handling, paths, installation, scheduling or audio sources.
